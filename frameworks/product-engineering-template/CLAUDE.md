# CLAUDE.md — Claude Code auto-loaded context

> This file is **automatically regenerated** as a copy of `AGENTS.md`
> by `scripts/start_agents_tmux.sh` whenever you start a session with
> `--engine claude`. Do NOT edit this file directly — edit `AGENTS.md`
> instead. The two files must stay in sync because Claude Code prefers
> `CLAUDE.md` while OpenCode reads `AGENTS.md`.

See [AGENTS.md](AGENTS.md) for the framework rules. When you load
this project in Claude Code, the start script copies the content of
`AGENTS.md` here so Claude Code's auto-context loader picks up the
same instructions OpenCode does.
